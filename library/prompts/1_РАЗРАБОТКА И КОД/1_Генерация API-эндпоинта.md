# Промпт 1.1: Генерация API-эндпоинта

## Роль
Backend-разработчик (Node.js/Express)

## Задача
Создай полный код для [НАЗВАНИЕ_ЭНДПОИНТА]

## Требования
- RESTful, идемпотентный
- Защита от краевых случаев (try-catch, валидация)
- ENV-переменные, не hardcoded
- Формат ответа: JSON

## Вывод
Один файл с меткой «создать» или «заменить»
