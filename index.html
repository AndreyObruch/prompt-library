🔄 Алгоритм использования

01

Определите задачу

Чётко сформулируйте, что нужно получить. «Помоги с кодом» → ✅ «Нужен API-эндпоинт для авторизации по PIN»

02

Выберите промпт

Откройте папку по типу задачи: Код → 1_РАЗРАБОТКА, ТЗ → 2_ДОКУМЕНТАЦИЯ, Спринты → 3_АНАЛИЗ, Интерфейсы → 4_UX_UI

03

Заполните плейсхолдеры

Замените всё в [КВАДРАТНЫХ СКОБКАХ] на ваши данные. Добавьте контекст проекта для точности.

04

Отправьте LLM

Вставьте заполненный промпт в чат. LLM ответит структурированно.

05

Уточняйте

Если результат не идеален: добавьте контекст, уточните ограничения, попросите альтернативу.

🛠 Как адаптировать промпты

01

Добавляйте контекст

Чем больше фактов о проекте, тем точнее ответ LLM. Указывайте стек, роли, ограничения.

02

Указывайте ограничения

«Только для 2-3 пользователей», «Без внешних мессенджеров», «Работает офлайн» — убирают «воду».

03

Требуйте формат вывода

Вместо «сделай хорошо» → «таблица с колонками X, Y, Z» или «один файл с меткой 'создать'».

04

Используйте мастер-шаблоны

Для сложных задач откройте УНИВЕРСАЛЬНЫЙ МАСТЕР-ШАБЛОН и заполните все 5 разделов.

⚡ PRO-советы

🎯

Задавайте роль конкретно

❌ «Ты — разработчик» → ✅ «Ты — Senior Backend с опытом в Node.js и Vercel»

Просите оценку уверенности

Добавьте: «Оцени уверенность по шкале 1-10 и укажи, чего не хватает для 10/10»

🔄

Требуйте альтернативы

«Предложи 2 варианта: консервативный (минимум рисков) и инновационный (максимум эффективности)»

🧠

Используйте Chain of Thought

Для сложных задач: «Проговори логические шаги перед финальным выводом»

🛡️

Запрещайте галлюцинации

«Если информации недостаточно, НЕ выдумывай факты. Задай 1-3 уточняющих вопроса»
